Solution by iteration

Conventions & algorithm

Select an operand size and a compatible system width. The prompt states n-bit unsigned integers. Enter the register widths yourself. Use one initialization row and one row after each complete iteration.

First version: initialize Q = 0, Div = divisor shifted left n bits, and REM = dividend with leading zeros.

  1. Subtract Div from REM. If the trial remainder is negative, restore REM and append 0 to Q; otherwise, keep the subtraction and append 1 to Q. Appending means shifting Q left and inserting that bit.
  2. Shift Div right by one bit. Record Q, Div, and REM after this shift.

Run exactly n + 1 iterations, including the first trial against the divisor in the upper half. There are n + 2 rows including initialization. REM contains the final remainder.

Div holds the unchanged divisor. REM initially holds the dividend in its lower half and zeros in its upper half. The lower half gradually becomes the quotient.

  1. Shift the combined REM register left by one bit.
  2. Subtract Div from the upper half of REM. If the trial is negative, restore the upper half and set REM bit 0 to 0; otherwise, keep the subtraction and set REM bit 0 to 1.
  3. Record Div and REM after this complete iteration. Div never shifts or changes.

Run exactly n iterations: n + 1 rows including initialization. Final REM = [remainder | quotient]: the upper half is the remainder and the lower half is the quotient.

Inputs have no character limit. Grading accepts 0, 1, and whitespace. Include all leading zeros. Use × in the leftmost cell to delete a row; + below the last row appends a new row. Division by zero is never generated.
