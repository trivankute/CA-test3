Solution

Representation & rounding rules

Let E be the number of exponent bits and F the number of fraction bits. Bias = 2^(E − 1) − 1. The sign field always has one bit. The total format uses 1 + E + F bits.

  • Normal: (−1)^sign × (1 + fraction / 2^F) × 2^(stored exponent − bias).
  • Subnormal: stored exponent = 0 and fraction ≠ 0. Value = (−1)^sign × (fraction / 2^F) × 2^(1 − bias).
  • Zero: exponent and fraction both zero. Preserve the sign for +0 or −0.
  • Infinity: exponent all ones, fraction all zeros. Sign determines +INF or −INF.
  • NaN: exponent all ones and a nonzero fraction. Either sign is allowed.
  • Rounding: select the nearest representable value. If exactly halfway, select the value whose last significand bit is even (0). A rounded carry may change the exponent or overflow to infinity.

Largest positive normal = (2 − 2^(−F)) × 2^bias. Smallest positive normal = 2^(1 − bias). Largest positive denormalized = (1 − 2^(−F)) × 2^(1 − bias). Smallest positive denormalized = 2^(1 − bias − F). Denormalized and subnormal refer to the same category.

Decimal → bits starts from the exact decimal value shown, before rounding. Part 3 always decodes that same rounded representation, so its value can differ from the original decimal. The bit pattern is shown after all three Part 1 fields are correct. You can enter the Part 3 answer at any time.

Reference: IEEE floating-point representation and round-to-nearest, ties-to-even. These rules are adapted to the smaller custom formats used here.
